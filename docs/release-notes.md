# KytyPS5 U59 int21

int21 brings DLSS & AMD FSR upscaling, Vulkan frame generation, an engine-aware optimization subsystem covering 17 engine families, major Unreal Engine 5 stability improvements, host VRAM budgeting, extensive memory and handle leak fixes, and modern C++20 architectural refactoring; older notes are in docs/release-notes-history.md. The first launch rebuilds the shader and program caches once, so the first minutes can stutter.

- **New (DLSS & FSR Upscaling):** integrated Vulkan 1.3 AMD FSR (EASU & RCAS) spatial upscaler and DLSS TSR temporal reconstruction into the swapchain presentation pipeline (`KYTY_UPSCALER=fsr|dlss|off`). Features an adjustable sharpness slider (`KYTY_SHARPNESS=0.0-1.0`) with contrast-adaptive sharpening to preserve edge clarity at lower native render resolutions.
- **New (Vulkan Frame Generation):** motion-interpolated frame generation filter (`KYTY_FRAME_GEN=1`) doubling visual presentation fluidity and frame pacing on high-refresh displays. Includes optimized sampler barriers and bandwidth management to eliminate stalls in heavy geometry scenes.
- **New (Qt6 Launcher Controls):** added interactive controls in the launcher settings dialog for upscaler selection (Off / FSR / DLSS), sharpness slider, and Frame Generation toggle. Command-line flags `--upscaler <off|fsr|dlss>`, `--dlss`, `--fsr`, `--sharpness`, and `--frame-gen` are available for CLI/headless launches.
- **New (Engine Profile Subsystem):** automatic executable detection and fingerprinting for 17 engine families (Unreal Engine 5, Decima, Insomniac, Team Asobi, RAGE, Frostbite, RE Engine, Unity, id Tech, Source 2, CryEngine, REDengine, Anvil, Snowdrop, Fox Engine, and Northlight) with engine-tailored presets under `tools/engine-presets/`.
- **Fixed & Optimized (Unreal Engine 5):** resolved Halloween frame stalls and RenderThread fence deadlock (`ppsa29340`), enabled RT stubbing and predication no-drain for UE5 compute dispatches, allowed host DLL SEH exceptions, added `tools/uecommandline.txt` presets, and disabled fast-first/array shrinking during compute to guarantee shader execution stability.
- **Fixed (Memory & Handle Leaks):** resolved thread handle, runtime memory page, and heap ownership leaks across pthread lifecycle, the runtime dynamic linker, filesystem read buffers, video decoder (Dec2), and audio subsystems.
- **New (Host VRAM Budgeting):** integrated host performance memory budgeting (`vramBudget.h`, `vma.cpp`) to monitor allocation limits against physical VRAM and safely evict scratch resources before driver memory exhaustion.
- **Smoother (Team Asobi & Dynamic Extent):** eliminated bandwidth spikes during dynamic resolution changes by synchronizing the presenter queue, optimizing fragment shader samplers, and fixing CP conditional execution.
- **Launcher Preset Discovery:** `tools/u59-preset.json` is now staged automatically beside the launcher on build/install and discovered via a multi-level fallback search covering application, parent, tools, and current directories.
- **Modernized (C++20 Refactoring):** cache-line aligned dense slot indexing (`SlotVector`), centralized runtime environment flags, thread-safe singletons replacing malloc singletons, and modern `std::variant`/`std::span`/`std::ranges` dispatch across ELF loading and system content parsing.
- **Known issues:** if you get a GPU device loss, reproduce it once with `KYTY_DEVICE_FAULT_DIAGNOSTICS=1` and Printf output set to File, then attach `_kyty.txt` and the `_kyty` folder to an issue; workaround: `KYTY_DEFER_PROTECTS=0` in `u59-preset.json`. If a level shows wrong graphics or freezes, try reporting it with detailed logs.
- **Upgrading:** extract into a new folder, or replace `u59-preset.json` too; an old preset keeps the old settings.
- **AMD, Intel and Linux users:** their fixes are in the int19 notes.
